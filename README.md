# book_marketplace_analysis
# Книжный маркетплейс: системный анализ
Полный цикл системного анализа книжного маркетплейса с интеграциями МойСклад (учёт товаров, резервы для заказов,
отгрузки),  Яндекс Доставка (доставка курьером до двери), ЮKassa (проведение платежа) и Unisender Go (отправка транзакционных писем)

## О проекте

Маркетплейс книг с четырьмя внешними интеграциями.  Реализует возможность регистрации, добавления товаров (для продавцов) и
выбора книг из общего каталога (для покупателей), оформления заказа с онлайн-оплатой и получением транзакционных уведомлений на всех этапах доставки. Асинхронные взаимодействия внутри платформы (доменные события, повторные попытки синхронизации, транзакционные письма) происходят с помощью брокера сообщений RabbitMQ

**Артефакты анализа:**
- Use case диаграмма
- BPMN диаграмма основного процесса (жизненный цикл заказа от создания до доставки)
- C4-модель (уровень контекста, контейнеров и компонентов)
- 5 sequence-диаграмм по ключевым сценариям
- ER-диаграмма базы данных
- Описание 26 эндпоинтов API 
- Реестр из 11 интеграционных сценариев с 4 внешними системами
- Спецификация интеграций, контракты запросов, маппинги полей, обработка ошибок по классам

## Бизнес-контекст и роли

**Четыре роли в системе**, каждая со своими use case и набором API:
- **Покупатель** — поиск книг, корзина, оформление и оплата заказа, история заказов
- **Продавец** — добавление и редактирование своих товаров, статистика продаж
- **Сотрудник склада** — список заказов на сборку, отметки этапов (собран, готов, передан курьеру), создание отгрузки в МойСклад
- **Администратор** — управление пользователями, модерация товаров, просмотр заказов и данных интеграций через встроенную админ-панель Django

Роли отражены в архитектуре: отдельные контроллеры (Catalog API для продавца, Warehouse API для склада сотрудника склада, User/Orders API для покупателя разграничение доступа через JWT с ролями, разная видимость данных.
